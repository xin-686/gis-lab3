（2）GeoJSON 专题地图

真实行政区 GeoJSON 的分级设色图与比例符号图，含点要素过滤与图例。

专题图参数

分级设色字段studyIndex（学习关注指数）
比例符号字段visitCount（调研访问次数）
点要素过滤importance >= 4
配色方案蓝色顺序色带（Blue Sequential）

配色方案说明

选用蓝色顺序色带（light blue → deep navy），从浅蓝 #dbeafe 到深蓝 #0b3c8a 共 5 级。适合表达从低到高的连续数量变化，符合"学习关注指数"的单向递增语义，避免使用发散色带造成"零值中心"的误导。

区域信息

将鼠标移到行政区查看详细属性。

（6）双变量专题图（加分项）

同时展示 studyIndex（学习关注指数）与 visitCount（访问次数）两个变量的空间分布关系。

双变量矩阵说明

采用 3×3 双变量色带矩阵，横轴为学习关注指数（低/中/高），纵轴为访问次数（低/中/高），共 9 种颜色组合。

配色方案

左下角（浅灰）：低关注 + 低访问；右上角（深蓝绿）：高关注 + 高访问。

对角线上颜色表示两变量同步递增，偏离对角线表示某一变量更突出。

区域信息

将鼠标移到行政区查看双变量属性。

（5）部署上线与拓展

本地运行指南、GitHub Pages 部署步骤、拓展方向说明。

本地运行（在线底图模式）

cd D:\GIS实验三
python -m http.server 8000

访问 http://localhost:8000/ 即可查看。底图使用 OSM 在线瓦片。

本地运行（PBF 矢量瓦片模式）

cd D:\GIS实验三
:: 启动瓦片服务（端口 8080）
npx tileserver-gl-light tiles-data\china.mbtiles -p 8080
:: 另开终端启动页面服务（端口 8000）
python -m http.server 8000

访问 http://localhost:8000/ ，页面自动检测本地瓦片服务。

GitHub Pages 部署

  1. 在 GitHub 新建仓库，上传项目文件。
  2. 进入 Settings → Pages，选择 main 分支根目录。
  3. 等待部署完成，获得 `https://用户名.github.io/仓库名/` 链接。
  4. 项目使用在线 OSM 底图，无需额外配置即可运行。

拓展功能说明

  • 双变量专题图：同时展示 studyIndex 与 visitCount 的 3×3 矩阵色带。
  • 标注编辑器：支持在地图上添加、编辑、删除自定义标注点并导出 GeoJSON。
  • 本地 PBF 底图：通过 Planetiler + tileserver-gl-light 将个人 OSM 数据转为矢量瓦片底图。
